# mini SWE Agent

A minimal SWE agent for automated programming task evaluation.

> ⚠️ **Warning**: This tool executes shell commands automatically. Use with caution.

## Requirements

- Python 3.10+

## Installation

```bash
pip install -e ".[dev]"
```

## Usage

```bash
mini-swe-agent --help
```
