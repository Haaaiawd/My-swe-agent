# ADR-002: 测试策略与质量门禁

**状态**: Accepted
**日期**: 2026-05-10

---

## 背景

需求 L 部分明确了验收测试（最低集），包括解析、提交、模板截断、轨迹存取、batch schema 冒烟、真机/火测默认关闭。

需要定义测试分层、质量门禁和验证时机。

---

## 决策

### 测试分层

| 测试层级 | 覆盖范围 | 优先级 | 说明 |
|---------|---------|--------|------|
| 单元测试 | 解析器、提交契约、模板截断、轨迹 schema | P0 | 需求明确要求 |
| 集成测试 | 核心闭环（成功路径 + FormatError + 提交失败） | P0 | 需求明确要求 |
| E2E 测试 | 真机/火测 | P1 | 默认关闭，环境变量启用 |
| 冒烟测试 | batch preds.json schema | P0 | 需求明确要求 |

### 质量门禁

| 门禁位置 | 检查内容 | 失败处理 |
|---------|---------|---------|
| PR | 单元测试 + lint | 阻止合并 |
| 提交前 | 集成测试通过 | 阻止提交 |
| 发布前 | E2E 测试（可选） | 警告 |

### 测试启用策略

- **真机/火测**：默认关闭，通过环境变量 `MINI_SWE_ENABLE_E2E` 启用
- **网络测试**：默认使用 mock，通过环境变量 `MINI_SWE_ENABLE_LIVE_API` 启用真实 API 调用

### 验收测试清单（来自需求 L）

- [ ] 解析：0 动作、2 动作、tool+文本冲突 → FormatError，无执行
- [ ] 提交：成功路径；returncode!=0 且含标记 → 不提交
- [ ] 模板截断 >=10000
- [ ] 轨迹存取；工具模式下关联字段存在
- [ ] batch preds.json schema 冒烟
- [ ] 真机/火测默认关闭；单一环境变量名在 README 中启用

---

## 影响范围

- 所有组件必须包含单元测试
- 核心闭环必须包含集成测试
- CI/CD 配置质量门禁
- README 文档化测试启用策略

---

## 后续行动

- 在 README 中说明环境变量
- 为每个验收测试项编写对应测试
