# Task Requirements

Create THREE HTML files. All must use only inline CSS and JavaScript (no external files).

---

## File 1: `clock.html`
- Dark-themed page with a live digital clock
- Shows current time (HH:MM:SS) updating every second
- Neon glow effect on the digits
- Show current date below the clock

## File 2: `matrix.html`
- Full-screen Matrix rain animation (falling green characters)
- Black background, green characters of varying brightness
- Characters should fall at different speeds
- Use canvas element

## File 3: `dashboard.html`
- A system-stats style dashboard (fake/mock data is fine)
- Show 4 panels: CPU%, Memory%, Network In/Out, Uptime
- Values should animate/update every second with random fluctuation
- Dark theme, monospace font, looks like a terminal monitor

---

## How to complete
1. Read this file first
2. Create each file one by one using bash commands (use printf or echo)
3. Verify each file exists after creating it
4. After ALL THREE files are created and verified, submit with:
   COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT
